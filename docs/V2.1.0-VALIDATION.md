```bash
npm run preflight

```

## Functional checks

- `/api/health` trả `version: 2.1.0`, release `Auto Generate Plan` và feature `auto-generate-plan`.
- Màn Plan có nút **Auto Generate Plan** tại header.
- Khi project chưa có Master Plan, màn empty state có lựa chọn Auto Generate Plan.
- Modal nhập được ngày bắt đầu/kết thúc, cách tính ngày và kiểu gợi ý.
- Preview hiển thị danh sách stage, số ngày, Từ ngày, Đến ngày và milestone đề xuất.
- Sau khi tạo, dữ liệu xuất hiện trong Project Stages, Timeline và Milestones.
- Có thể mở stage/milestone tự sinh để chỉnh thủ công.
- Chế độ thay thế bị chặn nếu project đã có task/checklist/reminder phụ thuộc.
