# V1.3.2 — Direct Excel Import Mapping

## File tham chiếu: IMP-PLHD-PhongBan.xlsx

Cấu trúc thực tế đã được dùng để thiết kế importer:

- `Phòng ban`: 9 dòng dữ liệu, tên nằm ở cột A.
- `PLHĐ`: 119 dòng dữ liệu, tên PLHĐ/Module nằm ở cột A.
- `PLHĐ chi tiết`: 73 dòng dữ liệu, cột A là mã và cột B là nội dung.

File không cần header, `key`, `parent_key`, `contract_item_key` hay sheet metadata.

### Quy tắc nhận diện mặc định

**PLHĐ**

- Dòng đầu tiên → `root`.
- Tên bắt đầu bằng `Phân hệ ...` → `subsystem`.
- Nếu hai dòng liên tiếp trùng tên, dòng trước → `subsystem`.
- Các dòng còn lại → `module`.

**PLHĐ chi tiết**

- `A/B/C...` → root/nhóm.
- `I/II/III...` → phân hệ.
- `1/2/3...` → node Module.
- `1.1`, `1,1`, `1.1.1`... → cấp chi tiết sâu hơn.
- Dòng không có mã → node con của cấp gần nhất.
- Nội dung node Module được đối chiếu với tên Module trong PLHĐ/Project để gắn `contract_item_id`.

Nếu file có thêm header/cột mở rộng, importer cũng hỗ trợ mã, loại, phòng ban phụ trách, trạng thái, phân loại, Module PLHĐ và ghi chú.


## Template chuẩn V1.3.2

Có thể tải trước từ nút **Tải mẫu Excel** tại Danh mục Project hoặc **Tải mẫu** trong modal Import. Template gồm `HƯỚNG DẪN`, `Phòng ban`, `PLHĐ`, `PLHĐ chi tiết` và không chứa dữ liệu Project cụ thể.
