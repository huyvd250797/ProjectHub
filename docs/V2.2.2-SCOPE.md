# ASC WORKING V2.2.2 — Scope

## Global Data Grid UX

V2.2.2 chuẩn hóa thao tác trên các lưới dữ liệu trong ASC WORKING.

### Added

- Global Grid Enhancer chạy trong App Shell để tự động nâng cấp các bảng dữ liệu chuẩn.
- Header cột có thể kéo thả để đổi vị trí hiển thị.
- Mép phải header có thể kéo để resize độ rộng cột.
- Layout cột được lưu theo từng route và từng cấu trúc header trong `localStorage`.
- ISSUE có resize cột riêng, đồng bộ với `IssueColumnPreferences`.

### Changed

- Nội dung dài trong các ô bảng được ưu tiên xuống hàng thay vì bị cắt.
- Các class phổ biến như `truncate` và `line-clamp` trong bảng được override ở phạm vi `.asc-data-grid`.
- PLHĐ tiếp tục dùng grid UX riêng đã có từ V2.2.1, không bị enhancer toàn cục ghi đè.

### Database

- Không cần migration mới.
- Không thay đổi schema, API contract hoặc dữ liệu Supabase.
