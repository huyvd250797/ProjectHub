# ASC WORKING V2.0.0 — Validation

## Automated

- `npm run typecheck`
- `npm run build`
- `npm run uat:preflight`

## Manual UAT

- Mở `/command-center`, chọn từng project và kiểm tra KPI/action/risk/timeline đổi theo project đang chọn.
- Double-click từng item navbar; màn đang mở phải reload lại dữ liệu và giao diện.
- Mở nút cấu hình navbar, kiểm tra mỗi dòng có **Tên gốc**, **Tên hiển thị** và href.
- Đổi tên hiển thị một module, lưu, tải lại trang và xác nhận sidebar dùng tên mới.
- Reset mặc định để trả lại thứ tự menu và tên gốc.
- Kiểm tra `/api/health` có feature `project-command-center`, `navbar-double-click-reload`, `navbar-display-labels`.
