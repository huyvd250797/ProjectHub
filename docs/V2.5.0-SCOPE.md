# ASC WORKING V2.5.0 - Resource Allocation Foundation

## Mục tiêu

V2.5.0 đặt nền móng phân bổ nguồn lực theo giờ để Workload trả lời được:

- Nhân sự có bao nhiêu giờ capacity trong tuần.
- Đã được giao bao nhiêu giờ planned work từ ISSUE/task.
- Còn trống bao nhiêu giờ hoặc đang vượt tải bao nhiêu giờ.
- Ai phù hợp nhận thêm việc dựa trên available hours.

## Phạm vi nâng cấp

- Bổ sung schema capacity cho `people`.
- Bổ sung `estimated_hours` cho `issues` và `project_plan_tasks`.
- Workload API tính `plannedHours`, `allocationPercent`, `availableHours`, `overloadHours`.
- Workload UI đổi KPI sang Planned Hours / Available Hours / Overload Hours / Avg Allocation.
- Modal ISSUE theo nhân sự hiển thị thêm Est. Hours.
- ISSUE drawer và Plan Task modal cho phép nhập giờ ước tính.
- Date picker toàn app dùng định dạng `DD/MM/YYYY`; date-time dùng `DD/MM/YYYY HH:mm`.

## Công thức hiện tại

- Effective capacity = `capacity_hours_per_week * allocation_target_percent / 100`.
- Planned hours = estimated hours của ISSUE + task + milestone + reminder đang mở.
- Allocation percent = `plannedHours / effectiveCapacityHours * 100`.
- Overloaded khi allocation >= 100%, vượt giờ capacity hoặc có nhiều overdue/blocked risk.
