# V0.9.2 Scope — Excel Import Production / Template Round-trip

## In scope
- Download project-scoped XLSX template
- Fill offline and upload back
- Validation + project mismatch protection
- Insert/update preview
- Merge / Insert-only apply modes
- Transactional Supabase import
- Stable import keys
- Import batch audit record
- Legacy workbook dry-run compatibility
- Resource metadata only; secrets excluded

## Out of scope
- Destructive replace-all import
- Automatic rollback of an already committed historical batch
- Importing passwords/tokens/secrets
- Arbitrary user-defined Excel layouts
