# Project Hub V0.2.0 — Data Model + Import POC

## Goal
Prepare the application for real data without coupling the workspace to EPU.

## Product rule
- **Project Hub = Project Workspace**.
- EPU is only the first project.
- Future projects reuse the exact same functional screens and database tables.
- Data isolation is by `project_id` and Supabase RLS.

## In scope
1. Multi-project data model.
2. Project membership and roles.
3. Project switcher foundation.
4. EPU seed as project #1.
5. Supabase migration + RLS foundation.
6. Import POC dry-run.
7. Workbook-to-table mapping report.
8. Data-quality warnings.
9. Remote secret exclusion.
10. HV logo as app brand and app icon.

## Out of scope
- Applying workbook data to business tables.
- Real Dashboard aggregate queries.
- Real ISSUE CRUD.
- Bulk update.
- Remote credential encryption/reveal.
- Notifications and Jira API sync.
