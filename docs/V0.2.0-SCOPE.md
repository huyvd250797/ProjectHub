# ASC-Working V0.2.0 — Data Model + Import POC

## Product identity
- ASC-Working = **Project Workspace**, không phải EPU Workspace.
- EPU = project đầu tiên đang hiển thị trên Dashboard.
- Các project tương lai dùng cùng UI, nhưng dữ liệu luôn được scope bằng `project_id`.

## Added
1. User-provided HV logo as main app logo + browser app icon.
2. Project selector foundation.
3. Multi-project PostgreSQL schema.
4. Basic Supabase RLS membership model.
5. EPU seed project.
6. Workbook Import Dry-run:
   - detect required sheets
   - count business records
   - map sheets → database tables
   - detect missing Module / Department / Assignee
   - detect unknown Module mappings
   - detect duplicate Jira links
   - exclude remote password/secret columns
7. `/api/health`.
8. `/settings/import` Data Migration Lab.

## Still out of scope

- Final tree-parent inference for PLHĐ chi tiết.
- CRUD live data on Dashboard/ISSUE.
- Remote credential encryption/reveal.
- Full audit log UX.

These continue in later roadmap versions.
