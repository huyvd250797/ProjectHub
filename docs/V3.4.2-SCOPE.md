# ASC WORKING V3.4.2 - Document Catalog Copy Polish

## Scope

V3.4.2 tinh chỉnh màn Document sau khi chuyển sang luồng lưu metadata + Google Drive link.

## Changes

- Ẩn đường link Google Drive khỏi lưới tài liệu.
- Giữ nút **Xem file** để mở link Drive trong tab mới.
- Thêm loại tài liệu **Biểu mẫu**.
- Thêm nút **Sao chép dòng** trên từng tài liệu.
- Khi sao chép, modal mở giống thêm mới và fill sẵn dữ liệu dòng gốc.
- Lưu modal sao chép sẽ tạo dòng mới bằng dữ liệu đã chỉnh sửa.

## Database

Migration `202609100001_v342_document_form_category.sql` mở rộng constraint category để nhận giá trị `form` và bỏ unique cũ trên `drive_file_id` để một link Drive có thể được sao chép/tham chiếu thành nhiều dòng metadata.
