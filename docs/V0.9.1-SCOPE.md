# ASC WORKING V0.9.1 — Scope

## Mục tiêu
Thêm một lớp quyền quản trị toàn cục trước V1.0.0 để ASC WORKING vận hành đúng mô hình multi-project.

## In scope
1. `global_role = master` trên profiles.
2. MASTER truy cập mọi project tự động.
3. RLS helpers hiểu MASTER.
4. ISSUE/Remote APIs nhận MASTER như effective Admin.
5. Master Project Console.
6. Tạo Project mới.
7. Active/Pause/Complete/Archive Project.
8. Gán Admin/PM/Member/Viewer theo email.
9. Bootstrap Project đầu tiên cho MASTER.
10. Hardening/UAT nhận diện MASTER.

## Out of scope
- Xóa cứng Project qua UI.
- Tạo Auth user mới từ Master Console.
- Impersonation user.
- Billing/licensing.
- Organization hierarchy nhiều tầng.

Các nội dung trên nếu cần sẽ nằm sau V1.0.0.
