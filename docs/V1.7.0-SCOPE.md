# ASC WORKING V1.7.0 — Scope

## Release name

Plan Execution & Tracking

## Mục tiêu

V1.7.0 nâng module Plan từ lập lịch sang theo dõi thực thi dự án. Sau khi đã có Master Plan, Project Stages, timeline và milestone ở V1.6.x, bản này bổ sung task chi tiết, checklist nghiệm thu và dashboard cảnh báo tiến độ.

## Added

- Execution Tasks theo Project, có thể gắn vào stage hoặc để độc lập.
- Task gồm tên, mô tả, stage, deadline, trạng thái, ưu tiên, người phụ trách và thứ tự.
- Trạng thái task: `todo`, `doing`, `blocked`, `done`.
- Ưu tiên task: `low`, `medium`, `high`, `critical`.
- Milestone Checklist để khai báo điều kiện hoàn thành cho từng milestone.
- Dashboard Plan bổ sung Execution Progress, task done, task sắp hạn, task quá hạn, task bị chặn và checklist completion.
- Health của kế hoạch tính thêm task bị chặn/quá hạn.
- Export CSV bổ sung phần Execution Tasks và Milestone Checklist.
- Demo Mode có dữ liệu task/checklist mẫu.

## Database

- Migration: `supabase/migrations/202609030003_v170_plan_execution_tracking.sql`.
- Bảng mới: `project_plan_tasks`.
- Bảng mới: `project_milestone_checklist_items`.
- RLS theo project membership.
- Chỉ MASTER/Admin/PM được thêm/sửa/xóa.
- Trigger validate liên kết stage/milestone/owner cùng Project.
- Trigger tự set `completed_at`.
- Activity Center ghi nhận thay đổi task/checklist.

## Không nằm trong scope

- Dependency giữa task/stage.
- Assignment theo team ngoài bảng `people`.
- Reminder tự động.
- Gantt nâng cao theo từng task.
- Export PDF đẹp.

Các phần này phù hợp để đưa sang V1.8.0/V1.9.0.
