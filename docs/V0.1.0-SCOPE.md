# ASC-Working V0.1.0 — Scope

## Mục tiêu
Tạo nền tảng có thể deploy ngay, xác nhận hướng UI/UX và kiến trúc trước khi đưa dữ liệu thật vào database.

## In scope
1. App shell
2. Authentication foundation
3. Demo mode
4. Dashboard shell
5. PLHĐ dual-view shell
6. Department shell
7. ISSUE grid shell
8. Remote resource shell
9. Settings / environment health
10. Vercel deploy documentation

## Out of scope
- Database business schema
- Import workbook
- CRUD ISSUE thật
- RLS business rules hoàn chỉnh
- Encryption credential
- Audit logs
- Bulk actions
- Real charts/aggregates

Những phần trên đi theo roadmap V0.2.0 → V1.0.0.
