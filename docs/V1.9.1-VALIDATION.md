# ASC WORKING V1.9.1 — Validation

## Regression chính

- Mở **Danh mục Module**.
- Xóa một hoặc nhiều Module chưa được sử dụng.
- Import lại file Excel danh sách Module.
- Preview phải hiển thị số lượng Module ở `summary.modules`.
- Apply Import thành công.
- Danh mục Module reload và hiển thị lại các Module vừa import.

## Kỹ thuật

- `parseContractItems` có chế độ flat module list khi chỉ import `contractItems`.
- `ProjectQuickImportButton` trong Danh mục Module truyền `initialSections={["contractItems"]}`.
- Không yêu cầu migration schema mới.
