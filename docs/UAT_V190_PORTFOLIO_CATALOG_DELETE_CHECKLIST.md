# UAT V1.9.0 — Portfolio & Catalog Delete

## Portfolio

- [ ] Sidebar có menu `Portfolio`.
- [ ] `/portfolio` tải được Cross-Project Portfolio Dashboard.
- [ ] `/api/portfolio` trả danh sách project user có quyền truy cập.
- [ ] KPI tổng hiển thị project, At Risk/Late, open issues, reminders và contract value.
- [ ] Project Ranking sắp xếp project có alert score cao lên trước.
- [ ] Priority Board chọn project và chuyển context đúng.

## Catalog Hard Delete

- [ ] Danh mục Phòng ban có checkbox từng dòng.
- [ ] Danh mục Module có checkbox từng dòng.
- [ ] Check all chỉ chọn các dòng đang hiển thị sau khi search/filter.
- [ ] Xóa phòng ban chưa được sử dụng thành công và biến khỏi danh sách.
- [ ] Phòng ban đang được dùng bởi ISSUE, People hoặc Module owner không bị xóa.
- [ ] Xóa Module chưa được sử dụng thành công và biến khỏi danh sách.
- [ ] Module đang được dùng bởi ISSUE, Contract Detail hoặc Module con không bị xóa.
- [ ] API trả message có số dòng đã xóa và số dòng bị chặn.
- [ ] Dữ liệu bị xóa là hard delete, không archive.

## Regression

- [ ] Thêm/sửa phòng ban vẫn hoạt động.
- [ ] Thêm/sửa Module vẫn hoạt động.
- [ ] Quick Import vẫn hoạt động.
- [ ] Dashboard, Plan, Smart Alerts và Reports vẫn tải được.
