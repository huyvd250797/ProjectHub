# V3.9.0 — Task Insights & Modal Stability

## Phạm vi

- Dashboard đọc trực tiếp `project_plan_tasks` theo Project và hiển thị tổng Task, trạng thái, quá hạn, phân công, tổng estimate, estimate còn lại, tỷ lệ phủ estimate và tỷ lệ hoàn tất.
- Analytics bổ sung cùng bộ số liệu Task, phân bổ trạng thái/ưu tiên, tín hiệu rủi ro và dữ liệu CSV export.
- Sửa validation Estimate tại API để nhận cả JSON number và numeric string, làm tròn tối đa hai chữ số thập phân.
- Chuẩn hóa các modal trung tâm bằng bốn lớp dùng chung: `asc-modal-viewport`, `asc-modal-panel`, `asc-modal-scroll`, `asc-modal-header/footer`.

## Quy tắc thống kê

- Quá hạn: `due_date` trước ngày hiện tại và trạng thái khác `done`.
- Chưa phân công: `owner_person_id` trống.
- Estimate còn lại: tổng `estimated_hours` của Task chưa `done`.
- Coverage estimate: số Task có giá trị `estimated_hours` chia tổng Task.
- Tỷ lệ hoàn tất: số Task `done` chia tổng Task.
