# ASC WORKING V1.9.2 — Validation

## UAT chính

- Import file có cây `subsystem → module → other`.
- Mở **Danh mục PLHĐ**: thấy `subsystem` và `module`.
- Mở **Danh mục chi tiết PLHĐ**: thấy các dòng `other`.
- Mở lưới PLHĐ bên ngoài: chỉ thấy `root/subsystem/module`, không thấy `other` như một dòng PLHĐ.
- Xóa một PLHĐ chưa được sử dụng trong danh mục: dòng đó biến mất khỏi lưới bên ngoài.
- Import lại danh sách: dữ liệu xuất hiện lại trong danh mục và lưới ngoài.
