# ASC WORKING V3.1.0 - Project Financial Control

## Mục tiêu

Bổ sung lớp quản lý tài chính dự án để Boss theo dõi giá trị hợp đồng, forecast, actual, revenue theo tháng, chi phí nhân sự và lợi nhuận dự kiến.

## Nâng cấp chính

- Thêm module **Tài chính** tại `/finance`.
- Thêm API `/api/finance`.
- Thêm bảng `project_financial_months` lưu dữ liệu tài chính theo tháng.
- Theo dõi theo từng tháng:
  - Forecast %.
  - Actual %.
  - Revenue.
  - Chi phí nhân sự.
  - Chi phí khác.
  - Lợi nhuận dự kiến.
  - Margin.
- Tự tính:
  - Forecast amount = contract value x forecast %.
  - Actual amount = contract value x actual %.
  - Total cost = staff cost + other cost.
  - Projected profit = revenue - total cost.
  - Projected margin = projected profit / revenue.
  - Remaining revenue = contract value - recognized revenue.
- Bổ sung biểu đồ nhanh Forecast vs Revenue.
- Bổ sung global modal scroll lock: khi modal mở, nền phía sau không bị scroll.

## Migration

Chạy migration mới:

```sql
supabase/migrations/202609080001_v310_project_financial_control.sql
```

## Phân quyền

- `admin`, `pm`: xem, thêm/sửa, xóa dữ liệu tài chính.
- `member`, `viewer`: chỉ xem dữ liệu tài chính.

## Ghi chú triển khai

- Dữ liệu tài chính bám theo `project_id` và tự xóa theo project qua `on delete cascade`.
- Module dùng `contract_value` hiện có trong bảng `projects`.
- Nếu chưa chạy migration V3.1.0, API sẽ trả `V310_MIGRATION_REQUIRED`.
