# ASC WORKING V1.3.2 — Bulk Master Data Import / Direct Excel

V1.3.2 giảm thao tác nhập tay khi khởi tạo hoặc cập nhật danh mục Project bằng cách import trực tiếp Excel cho **Phòng ban**, **PLHĐ** và **PLHĐ chi tiết**.

## Hỗ trợ trực tiếp file Excel hiện có

Không bắt buộc phải chuyển dữ liệu sang template có `key`, `parent_key`, `contract_item_key` hay `__META`.

App nhận diện các sheet sau (không phân biệt một số biến thể tên):

- `Phòng ban`
- `PLHĐ`
- `PLHĐ chi tiết` hoặc `PLHĐ - Chi tiết`

Định dạng tối giản được hỗ trợ:

- **Phòng ban:** cột A = Tên phòng ban; cột B nếu có = Mã phòng ban.
- **PLHĐ:** cột A = Tên PLHĐ/Module. Có thể chỉ dùng một cột như file triển khai hiện tại.
- **PLHĐ chi tiết:** cột A = Mã; cột B = Nội dung. Cột C nếu có = Module PLHĐ; cột D nếu có = Ghi chú.
- File có header hoặc không có header đều được hỗ trợ.

## Tự nhận diện cấu trúc PLHĐ

Khi sheet PLHĐ chỉ có một cột, hệ thống tự suy luận Nhóm / Phân hệ / Module theo thứ tự và tên dữ liệu. Với PLHĐ chi tiết, mã dạng A/B/C, I/II/III, 1/2/3, 1.1 hoặc 1,1... được dùng để dựng cây cha-con; dòng không có mã được hiểu là nghiệp vụ con của node gần nhất.

Hệ thống cố gắng tự mapping PLHĐ chi tiết về Module dựa trên tên Module. Các dòng chưa mapping được vẫn được Preview và cảnh báo để người dùng kiểm tra trước Apply.

## Xuất mẫu trước khi nhập

Trong **Danh mục Project** có nút **Tải mẫu Excel** luôn hiển thị để tải file mẫu trước, sau đó người dùng fill dữ liệu vào đúng các sheet/cột và quay lại Import. Trong modal Import cũng giữ nút **Tải mẫu** để thao tác nhanh.

## Luồng thao tác

1. Chọn Project đích.
2. Bấm **Import Phòng ban** hoặc **Import PLHĐ / Chi tiết**.
3. Chọn/kéo thả file `.xlsx`.
4. Chọn nhóm dữ liệu cần import.
5. Bấm **Preview dữ liệu**.
6. Kiểm tra số dòng, cấu trúc, cảnh báo và thống kê **Thêm / Cập nhật**.
7. Nhập đúng mã Project để xác nhận.
8. Bấm **Apply Import**.

Apply chạy theo chế độ **Merge** trong một transaction: dữ liệu khớp được cập nhật, dữ liệu mới được thêm, dữ liệu ngoài file không bị xóa.

## Chống trùng khi import lại

Migration V1.3.2 đảm bảo `import_key` cho dữ liệu Phòng ban / PLHĐ / PLHĐ chi tiết. Import nhanh còn đối chiếu theo business identity (tên chuẩn hóa, loại PLHĐ, mã/nội dung chi tiết) và tải key hiện có trước khi parse để import lại cùng file không tạo bản ghi trùng một cách không cần thiết.

## Vị trí thao tác

- **Phòng ban** → `Import Phòng ban` (mặc định chỉ chọn Phòng ban).
- **PLHĐ** → `Import PLHĐ / Chi tiết` (mặc định chọn PLHĐ + PLHĐ chi tiết).
- **Danh mục Project** → nút Import thay đổi phạm vi theo tab đang mở.

## Quyền và an toàn

- MASTER/Admin/PM: Preview + Apply.
- Member/Viewer: không được Apply.
- File `.xlsx` tối đa 20 MB.
- Không hard-delete dữ liệu ngoài file.
- Ghi `import_batches` để lưu dấu lần import.
- Không cần Environment Variable mới.
