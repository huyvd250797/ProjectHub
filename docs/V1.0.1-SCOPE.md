# ASC WORKING V1.0.1 — Dark Mode Contrast & Visual Polish

## Mục tiêu
Tinh chỉnh giao diện Dark Mode sau Production Release để tăng khả năng đọc và độ phân tầng thị giác, không thay đổi nghiệp vụ.

## Thay đổi
- Nền tổng thể chuyển từ gần-black sang deep navy sáng hơn.
- Panel và control được nâng surface level, border rõ hơn.
- Chuẩn hóa dark text ramp để text phụ vẫn đủ tương phản.
- Placeholder/input/select và metadata grid rõ hơn.
- Theme toggle rõ trạng thái và hover hơn.
- Light Mode giữ nguyên.
