# ASC WORKING V1.1.1 — Issue Validation / Flexible Project Team / Performance Tune

## Mục tiêu
Hotfix + UX/performance release sau V1.1.0, tập trung vào ba điểm vận hành thực tế:

1. Tạo/cập nhật ISSUE phải báo chính xác field thiếu hoặc sai.
2. Project Team cho phép khai báo nhân sự trước khi có email/tài khoản đăng nhập.
3. Giảm request thừa và tăng tốc ISSUE/search/background polling.

## Thay đổi chính

- Client validation trước khi gửi request tạo ISSUE.
- API validation trả `fieldErrors` theo từng field.
- Database error phổ biến được chuyển thành thông báo nghiệp vụ dễ hiểu.
- `people` là danh sách Project Team/Phụ trách; `project_members` chỉ đại diện quyền đăng nhập khi đã liên kết Supabase Auth.
- Email Project Team là tùy chọn.
- Nhân sự chưa có email vẫn được giao ISSUE và thống kê workload.
- Khi bổ sung email trùng profile Supabase, hệ thống tự liên kết `user_id` + `project_members`.
- ISSUE summary dùng một RPC aggregate thay vì nhiều count query.
- Assignee lookup bỏ các profile/membership query không cần thiết.
- Hủy request ISSUE cũ khi filter/search thay đổi nhanh.
- Notification polling không chạy khi tab browser bị ẩn.
