# ASC WORKING V3.1.0 - Validation

## Preflight

Chạy:

```bash
npm run preflight
```

Kỳ vọng:

- Package version là `3.1.0`.
- Có đủ page `/finance`.
- Có đủ API `/api/finance`.
- Có đủ `lib/finance/types.ts`, `lib/finance/server.ts`, `lib/finance/demo.ts`.
- Có đủ migration `202609080001_v310_project_financial_control.sql`.
- Navbar có module **Tài chính**.
- Health API có feature `project-financial-control`.
- Readiness API có check `project_financial_control`.
- AppShell có `GlobalModalScrollLock`.

## UAT thủ công

1. Chạy SQL V3.1.0.
2. Vào module **Tài chính**.
3. Kiểm tra Contract Value lấy đúng từ hồ sơ project.
4. Bấm **Thêm tháng**.
5. Nhập forecast %, actual %, revenue, chi phí nhân sự, chi phí khác.
6. Kiểm tra form tự tính forecast amount, actual amount, profit và margin.
7. Lưu lại và kiểm tra bảng tháng cập nhật đúng.
8. Sửa một tháng đã có, lưu lại và kiểm tra summary cập nhật.
9. Xóa một tháng, kiểm tra summary và biểu đồ cập nhật.
10. Mở bất kỳ modal nào trong app, thử cuộn nền phía sau. Kỳ vọng: chỉ modal được cuộn, nền đứng yên.

## Lưu ý

- V3.1.0 có migration mới vì cần lưu dữ liệu tài chính theo tháng.
- Không thay đổi dữ liệu ISSUE, PLHĐ, Workload hoặc Allocation hiện có.
