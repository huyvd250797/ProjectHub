# ASC WORKING V1.9.1 — Scope

Catalog Import Module Resync

## Mục tiêu

Sửa lỗi sau khi xóa Module chưa sử dụng bằng hard delete rồi import lại danh sách Module, dữ liệu mới phải xuất hiện ngay trong **Danh mục Module**.

## Thay đổi

- Import từ **Danh mục Module** mặc định chỉ chọn `PLHĐ / Module`.
- File Excel dạng danh sách Module phẳng được nhận diện là danh sách `module`, không tự biến dòng đầu thành `root`.
- Sau Apply Import, modal Danh mục Module reload lại dữ liệu và hiển thị các module vừa import.
- Luồng import PLHĐ phân cấp ở trang Contract vẫn giữ nhận diện Nhóm / Phân hệ / Module khi import kèm PLHĐ chi tiết.
