# ASC WORKING V2.6.0 - Resource Scheduling & Assignment Board

## Mục tiêu

V2.6.0 biến nền tảng Resource Allocation của V2.5.0 thành màn điều phối thực tế cho PM: nhìn theo tuần, kéo thả ISSUE/task giữa các nhân sự, nhận cảnh báo overload trước khi giao việc.

## Phạm vi nâng cấp

- Thêm module **Phân bổ** tại `/resource-scheduling`.
- Load dữ liệu từ ISSUE và Execution Task đang mở.
- Hiển thị board 6 tuần từ ngày bắt đầu người dùng chọn.
- Mỗi nhân sự có capacity/tuần, planned hours, available hours, overload hours và allocation %.
- Queue việc chưa phân công cho ISSUE/task chưa có assignee/owner.
- Kéo thả card vào nhân sự hoặc chọn người phụ trách bằng combobox.
- API cập nhật phân công:
  - ISSUE: cập nhật `issues.assignee_person_id`.
  - Task: cập nhật `project_plan_tasks.owner_person_id`.
- Ghi audit vào `resource_assignment_events`.
- Date input cho phép nhập tay hoặc chọn date picker, hiển thị `DD/MM/YYYY`.

## Migration

Chạy sau V2.5.0:

`supabase/migrations/202609070002_v260_resource_scheduling_assignment_board.sql`

Migration tạo bảng audit nhẹ `resource_assignment_events`, có RLS cho thành viên project xem và Admin/PM ghi lịch sử điều phối.
