# V0.9.5 Deploy Type Fix

## Error

Vercel stopped at `Running TypeScript` with `TS2677` in `lib/issues/server.ts`.

## Cause

The assignee `.map()` callback was inferred as returning an object whose `description` property was always `string`, or `null`. The subsequent type predicate widened that object to the shared `SelectOption` type where `description` is optional/nullable, so TypeScript rejected the predicate.

## Fix

The `.map()` callback now explicitly returns `SelectOption | null` before the null-filter type guard:

```ts
.map((membership): SelectOption | null => {
  // ...
})
.filter((option): option is SelectOption => Boolean(option))
```

No SQL migration or Supabase configuration change is required.
