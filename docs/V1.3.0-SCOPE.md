# ASC WORKING V1.3.0 — Executive Report & Project Summary

## Scope

- `/reports` Executive Report theo Project.
- Kỳ báo cáo: tuần, tháng, 30 ngày, 90 ngày, toàn bộ, tùy chọn.
- Project Health / schedule / ISSUE / handover / attention / risk ranking.
- Drill-down từ báo cáo về ISSUE đã filter.
- PM Comment + Kế hoạch tiếp theo.
- Snapshot cho so sánh kỳ.
- CSV + Browser Print/Save PDF.
- Dùng chung preference ẩn/hiện giá trị hợp đồng.
- ISSUE Full Screen: fixed viewport, không sidebar/topbar, một scroll lưới ISSUE, Esc để thoát.
