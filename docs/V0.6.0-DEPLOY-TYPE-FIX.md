# ASC WORKING V0.6.0 — Deploy Type Fix

## Lỗi Vercel

```text
Type 'SelectOption[]' is not assignable to type 'ThemedSelectOption[]'.
Types of property 'description' are incompatible.
Type 'string | null | undefined' is not assignable to type 'string | undefined'.
```

## Nguyên nhân

`lib/issues/types.ts` định nghĩa dữ liệu lookup từ Supabase:

```ts
description?: string | null;
```

Trong khi `components/ui/themed-select.tsx` trước đây định nghĩa lại option với:

```ts
description?: string;
```

Vì các lookup Module, Department, Assignee... có thể không có mô tả phụ nên server trả `null` là hợp lệ. Type của UI phải chấp nhận cùng contract đó.

## Cách sửa

`ThemedSelectOption` dùng trực tiếp `SelectOption` làm base type:

```ts
import type { SelectOption } from "@/lib/issues/types";

export type ThemedSelectOption = SelectOption & {
  disabled?: boolean;
};
```

Không dùng `any`, không ép kiểu tại `issue-workspace.tsx`, không thay đổi dữ liệu Supabase.

## Phạm vi ảnh hưởng

Fix áp dụng cho toàn bộ `ThemedSelect` dùng lookup ISSUE:

- Trạng thái
- Ưu tiên
- Phòng ban
- Trạng thái khách hàng
- Giai đoạn
- Module
- Người phụ trách

## Deploy

Không cần chạy SQL migration mới. Chỉ commit/push source đã fix để Vercel build lại.
