# ASC WORKING V1.1.0 — Notifications & Activity Center

## Mục tiêu
Biến icon chuông hiện có thành Notification Inbox thật và bổ sung Activity Feed theo Project mà không làm thay đổi nghiệp vụ cốt lõi.

## In scope
- Notification Bell + unread badge.
- Mark read / mark all read.
- Deep-link tới ISSUE / Project / Import / Resource.
- Activity Feed theo Project.
- Filter Activity.
- Per-user/per-project notification preferences.
- ISSUE assignment/update notification.
- Due Reminder lazy sync.
- Project Member notification.
- Excel Import activity + notification cho PM/Admin/MASTER khác actor.
- Resource Vault activity + security notification cho PM/Admin/MASTER.
- 30-day activity backfill.

## Out of scope
- Email notification.
- Push notification / mobile push.
- Slack/Teams integration.
- Scheduled daily/weekly digest.
- Realtime WebSocket subscription; V1.1.0 poll mỗi 60 giây.
