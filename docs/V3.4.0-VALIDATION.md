# V3.4.0 — Validation Guide

## Kiểm tra tự động

```bash
npm ci
npm run preflight
npm run typecheck
npm run lint
npm run build
```

## Kiểm tra dữ liệu lớn

1. Dùng Project có tối thiểu 1.000 ISSUE, 500 dòng PLHĐ/chức năng và nhiều nhân sự.
2. ISSUE: chuyển trang, tìm kiếm, lọc Module/phòng ban, mở Full Screen và quay lại trang trước.
3. PLHĐ: mở/thu gọn cây, tìm kiếm Function, kéo ngang grid; xác nhận nội dung dài vẫn xuống hàng.
4. Workload: lọc nhân sự, mở modal ISSUE, đóng modal; xác nhận không gọi API lặp liên tục.
5. Allocation: đổi tuần, reload, kéo thả assignment; xác nhận dữ liệu sau ghi được tải mới.
6. DevTools Network: request giống nhau trong TTL phải được dùng lại; sau mutation/reload phải có request mới.
7. Chạy migration index rồi kiểm tra `EXPLAIN (ANALYZE, BUFFERS)` cho các truy vấn lọc theo `project_id`.

## Tiêu chí đạt

- Không thay đổi số lượng hoặc nội dung bản ghi.
- Không render toàn bộ hàng ngoài viewport khi danh sách lớn.
- API vẫn tách dữ liệu theo Project/RLS.
- Không có lỗi console, TypeScript, lint hoặc build.
