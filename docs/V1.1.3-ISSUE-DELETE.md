# ASC WORKING V1.1.3 — ISSUE Delete / CRUD Completion

## Mục tiêu
Hoàn thiện CRUD cho ISSUE: Create / Read / Update / Delete.

## Hành vi xóa
- Xóa một ISSUE từ drawer chi tiết bằng nút `Xóa ISSUE`.
- Xóa nhiều ISSUE bằng checkbox + thanh Bulk Action.
- Có bước confirm trước khi xóa.
- Xóa là **soft delete**: cập nhật `issues.archived_at`.
- ISSUE đã xóa không còn xuất hiện trong danh sách active, Dashboard/summary/export active.
- Không hard-delete để bảo toàn lịch sử và audit.

## Quyền
- MASTER / Admin / PM / Member có quyền chỉnh sửa ISSUE: được xóa.
- Viewer: chỉ xem, không xóa.

## Database
Không cần migration mới. Cột `archived_at` đã có trong schema ISSUE Core.
