# ASC WORKING V3.7.0 - Module Data Export

## Mục tiêu

Bổ sung chức năng export dữ liệu cho từng module nghiệp vụ để PM có thể tải dữ liệu đang xem, gửi đối chiếu hoặc lưu snapshot báo cáo mà không cần thao tác thủ công trên lưới.

## Module xử lý

| Module | Phạm vi export |
| --- | --- |
| Dashboard | Tổng quan project, KPI ISSUE, Stage, Department, Workload member |
| Plan | Giữ export Master Plan / Stages / Milestones / Tasks / Alerts hiện có |
| Finance | Forecast %, Actual %, Revenue, Staff Cost, Other Cost, Profit theo tháng |
| PLHĐ / Contract | Cây Nhóm / Phân hệ / Module / Chức năng theo filter hiện tại |
| Department | KPI phòng ban theo filter/sort hiện tại |
| ISSUE | Giữ export server theo bộ lọc hiện có |
| Workload | Tải việc nhân sự theo filter hiện tại và export ISSUE trong modal nhân sự |
| Allocation | Unassigned work queue và weekly assignment board |
| Analytics | Giữ export Project Health hiện có |
| Report | Giữ export Executive CSV/PDF hiện có |
| Document | Danh sách tài liệu metadata, không hiển thị URL Drive trong lưới |
| Activity | Activity Center theo filter/trang hiện tại |
| Remote Server | Metadata tài nguyên an toàn, không export secret/password |
| Command Center | Action Board, Risk Radar, Stages, Milestones |
| Portfolio | Danh sách project và KPI portfolio |
| Master Console | Danh sách project master và số thành viên |
| Data Integrity | Findings theo filter hiện tại |

## Nguyên tắc

- Export theo dữ liệu đang hiển thị hoặc đang lọc trên từng màn.
- File CSV có BOM để mở Excel không lỗi tiếng Việt.
- Không thêm migration mới.
- Không export dữ liệu nhạy cảm như credential secret/password.
