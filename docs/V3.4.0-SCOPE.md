# ASC WORKING V3.4.0 — Performance & Large Data Optimization

## Mục tiêu

Giảm thời gian phản hồi và chi phí render khi Project có nhiều ISSUE, PLHĐ, chức năng, nhân sự, task hoặc assignment. Bản này giữ nguyên luồng nghiệp vụ, chỉ tối ưu cách truy vấn, cache và hiển thị.

## Phạm vi

- ISSUE: giữ phân trang server, giảm tải khi tìm kiếm/chuyển trang và không khuyến khích render toàn bộ cùng lúc.
- PLHĐ: cache dữ liệu theo Project, giảm paint các dòng ngoài viewport, giữ expand/collapse và nội dung xuống hàng.
- Workload/Allocation: cache request ngắn hạn, chống request trùng khi reload/chuyển Project/tuần.
- Database: index additive theo `project_id` và các cột lọc/sắp xếp thường dùng.

## Nguyên tắc

- Cache chỉ ngắn hạn; sau thao tác ghi hoặc reload thủ công sẽ invalidate.
- Không dùng mock để che lỗi dữ liệu thật.
- Không thay đổi quyền RLS hay logic tính toán tải việc.
- Migration chỉ tạo index `IF NOT EXISTS`; không sửa hoặc xóa dữ liệu.
