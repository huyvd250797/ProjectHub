# ASC WORKING V0.3.0 — Dashboard / Real Project Data

## Mục tiêu
Biến Dashboard từ seed/mock UI thành Dashboard đọc dữ liệu Supabase thật theo project đang chọn.

## Định vị sản phẩm
- **ASC WORKING** là tên ứng dụng.
- **Project Workspace** là loại sản phẩm/workspace.
- **EPU** chỉ là project đầu tiên, không phải tên workspace.
- Tất cả Dashboard dùng chung UI và tách dữ liệu bằng `project_id`.

## In scope
- Đổi branding ASC WORKING → ASC WORKING.
- Giữ nguyên logo HV đã được người dùng cung cấp.
- Project Switcher điều khiển Dashboard thật.
- Server API `/api/dashboard?projectId=...`.
- Supabase RPC `get_project_dashboard` để aggregate server-side.
- Project Overview.
- Master Plan / time health.
- Project Stages.
- ISSUE KPI + handover KPI.
- Needs Attention.
- Contract Pulse.
- Department ranking.
- ASC member workload.
- Loading / empty database / migration-required states.

## Out of scope
- Apply Import vào database.
- PLHĐ tree hoàn chỉnh.
- Department detail CRUD.
- ISSUE CRUD đầy đủ.
- Remote secret encryption.

Các phần trên tiếp tục theo roadmap V0.4.0 → V1.0.0.
