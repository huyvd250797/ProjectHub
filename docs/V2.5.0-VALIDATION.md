# ASC WORKING V2.5.0 - Validation

## Resource Allocation

- Chạy migration V2.5.0 thành công trên Supabase.
- Readiness hiển thị check **Resource Allocation Foundation** pass.
- Workload hiển thị Planned Hours, Available Hours, Overload Hours và Avg Allocation.
- Người có planned hours vượt effective capacity được đánh dấu quá tải.
- Assignment Suggestions ưu tiên người còn nhiều available hours.
- Bấm tên nhân sự vẫn mở modal ISSUE full-screen và không rời khỏi Workload.
- Modal ISSUE hiển thị Est. Hours từng ISSUE.

## Nhập liệu

- ISSUE drawer cho phép nhập Giờ ước tính và lưu lại.
- Plan Task modal cho phép nhập Giờ ước tính và lưu lại.
- Nhân bản ISSUE giữ lại estimated hours.
- Khi task chuyển Done, estimated hours không bị mất.

## Date Picker

- Các ô ngày trong ISSUE, Plan, Master Project Console, bulk update và Report custom period hiển thị/nhập `DD/MM/YYYY`.
- Các ô ngày giờ Reminder/Snooze hiển thị/nhập `DD/MM/YYYY HH:mm`.
- API vẫn nhận/lưu ISO `YYYY-MM-DD` hoặc ISO datetime để tương thích database.
