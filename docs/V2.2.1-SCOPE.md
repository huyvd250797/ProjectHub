# ASC WORKING V2.2.1 — Scope

## PLHĐ Grid UX

V2.2.1 là hotfix giao diện cho màn PLHĐ trên nền V2.2.0.

- Đổi tiêu đề bảng thành **Cấu trúc PLHĐ**.
- Header PLHĐ hỗ trợ kéo đổi vị trí cột.
- Header PLHĐ hỗ trợ kéo resize độ rộng cột.
- Nội dung dài trong dòng PLHĐ tự xuống hàng, không bị cắt bằng dấu ba chấm.
- Combobox trạng thái Module/Phân hệ gọn hơn để tránh đè vào cột kế bên.

## ISSUE Jira Code

- Cột Jira rút mã ticket từ URL dạng `/browse/PROJECT-123`.
- Link vẫn mở trực tiếp URL Jira đã cấu hình.
- Nếu URL không có `/browse/`, app fallback sang segment cuối của URL hoặc nhãn `Jira`.
