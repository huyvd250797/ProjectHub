# ASC WORKING V3.0.0 - Validation

## Preflight

Chạy:

```bash
npm run preflight
```

Kỳ vọng:

- Package version là `3.0.0`.
- Có đủ file `app/(workspace)/enterprise/page.tsx`.
- Có đủ API `app/api/enterprise/route.ts`.
- Có đủ `components/enterprise/enterprise-suite.tsx`.
- Có đủ `lib/enterprise/types.ts`, `lib/enterprise/server.ts`, `lib/enterprise/demo.ts`.
- Navbar có `Enterprise Suite`, `/enterprise`, `ShieldCheck`.
- Workspace preference có `/enterprise`.
- Health API trả `Enterprise Project Suite` và feature flags V3.
- Readiness API có check `enterprise_project_suite`.

## UAT thủ công

1. Vào navbar, chọn `Enterprise Suite`.
2. Kiểm tra màn hình hiển thị đúng project hiện tại.
3. Bấm nút refresh để reload dữ liệu.
4. Kiểm tra các KPI:
   - Maturity Score.
   - Open ISSUE.
   - Execution.
   - Overloaded.
   - Scope.
   - Snapshots.
5. Kiểm tra từng Readiness Gate có score, trạng thái và nút điều hướng.
6. Bấm các action trong Priority Board để chuyển về ISSUE/Plan đúng module.
7. Kiểm tra bảng `PMO Operating Model` có thể kéo/resize cột nhờ Global Grid Enhancer.
8. Double click item navbar `Enterprise Suite` để reload lại giao diện và dữ liệu module.

- Không chạy migration mới cho V3.0.0.
