# ASC WORKING V3.0.0 - Enterprise Project Suite

## Mục tiêu

Chuẩn hóa ASC WORKING thành lớp quản trị dự án chuyên nghiệp ở cấp Enterprise/PMO, bỏ qua các nhánh Jira Sync V2.8 và V2.9 theo nhu cầu hiện tại.

## Nâng cấp chính

- Thêm module `Enterprise Suite` tại `/enterprise`.
- Thêm API `/api/enterprise` tổng hợp dữ liệu theo project hiện tại.
- Tạo `PMO maturity score` dựa trên dữ liệu ISSUE, Plan, Workload, PLHĐ và Report.
- Bổ sung `Enterprise Readiness Gates`:
  - Data Quality Gate.
  - Delivery Control Gate.
  - Resource Control Gate.
  - Executive Reporting Gate.
  - Scope Governance Gate.
- Bổ sung `PMO Operating Model` để chuẩn hóa owner, cadence và metric vận hành.
- Bổ sung `Priority Board` cho các hành động quản lý cần xử lý trước.
- Cập nhật `Health` và `Readiness` metadata lên V3.0.0.

## Dữ liệu sử dụng

- `projects`
- `issues`
- `contract_items`
- `contract_detail_items`
- `departments`
- `project_stages`
- `project_plan_tasks`
- `project_milestones`
- `project_plan_reminders`
- `people`
- `report_snapshots`

## Migration

Không có migration mới trong V3.0.0. Phiên bản này dùng lại schema đã có đến V2.6.1.

## Điều kiện vận hành

- Cần chạy đầy đủ migration nền đến V2.6.0/V2.6.1.
- Nếu chưa chạy SQL V2.6.0 SQL Fix thì cần chạy trước để `resource_assignment_events` và RLS helper đúng.
- Nếu chưa có dữ liệu Supabase, màn hình vẫn chạy bằng demo mode.
