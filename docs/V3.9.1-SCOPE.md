# V3.9.1 — ISSUE Modal Viewport Hotfix

## Nguyên nhân

`IssueDrawer` nằm bên trong `main.asc-page-enter`. Animation cũ dùng fill mode `both`, vì vậy `transform: translateY(0)` vẫn tồn tại sau animation và biến `main` thành containing block cho phần tử `position: fixed`. Khi trang đã cuộn, modal bị căn theo vùng nội dung thay vì viewport, làm phần footer nằm ngoài màn hình.

## Hiệu chỉnh

- Dùng React `createPortal` đưa `IssueDrawer` vào `document.body`.
- Bỏ fill mode `both` khỏi animation `asc-page-enter` để `transform` được giải phóng sau 180 ms.
- Giữ chuẩn modal V3.9.0: `100dvh`, safe-area, panel `min-height: 0`, body cuộn độc lập, header/footer không co.
- Di chuyển Task Control trong Dashboard xuống ngay sau ISSUE Control.
