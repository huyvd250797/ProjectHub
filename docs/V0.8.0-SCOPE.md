# ASC WORKING V0.8.0 — Remote Server Security

## In scope
- Real resource list scoped by selected project.
- CRUD Portal/Server/Database/Folder/Test/Other.
- Environment categorization.
- AES-256-GCM server-side credential encryption.
- Service-role-only secret table access.
- Reveal 10 seconds / Copy with permission check.
- PM/Admin default secure access; Member grants foundation.
- Security audit trail.
- Search/filter and secure resource drawer.
- No secret in list API, logs, URL or exports.

## Out of scope
- Enterprise KMS/HSM integration.
- Automatic credential rotation.
- External secret manager integration.
- SSO re-authentication before every reveal.

These can be considered after V1.0.0.
