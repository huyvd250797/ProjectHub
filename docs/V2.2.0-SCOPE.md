# ASC WORKING V2.2.0 — Scope

## PLHĐ Function Tree

V2.2.0 hiệu chỉnh PLHĐ về một luồng duy nhất:

- `contract_items`: Nhóm / Phân hệ / Module.
- `contract_detail_items`: Chức năng nằm dưới Module.
- Màn PLHĐ bên ngoài chỉ còn một cây: Nhóm -> Phân hệ -> Module -> Chức năng.
- Các cấp có con cho phép collapse / expand.
- Dòng `other` hoặc `khác` từ dữ liệu cũ được chuẩn hóa và hiển thị là `function`.

## Danh Mục PLHĐ

- Project Master Data không còn tab riêng “Chi tiết PLHĐ”.
- Tab PLHĐ hiển thị chung Nhóm / Phân hệ / Module và Chức năng.
- Chức năng vẫn có form riêng trong cùng tab để PM chỉnh nội dung, mapping Module, cấp cha, thứ tự và ghi chú.
- Import PLHĐ vẫn đọc đủ dữ liệu cũ; dòng `other/khác/chức năng` trong file import được đưa vào Chức năng.

## Trạng Thái Module

- Trên màn PLHĐ có thể sửa trực tiếp trạng thái từng dòng Phân hệ hoặc Module.
- Nhóm và Chức năng không được cập nhật trạng thái trực tiếp.
- API guard ở `/api/project-catalog` chặn cập nhật trạng thái sai loại dòng.

## Xóa Project

- Master Project Console bổ sung xóa Project.
- Người dùng phải nhập đúng mã Project để xác nhận.
- API chỉ cho MASTER xóa.
- Xóa Project là hard delete; dữ liệu có `project_id` liên quan được xóa qua FK cascade hiện có.
