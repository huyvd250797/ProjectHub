# ASC WORKING V0.9.0 — Hardening + UAT Scope

## Mục tiêu
Ổn định toàn bộ hệ thống trước V1.0.0. Không thêm phân hệ nghiệp vụ lớn.

## In scope
- Production Readiness API + UAT Center.
- Security headers.
- Route loading/error/not-found states.
- Multi-project access hardening; không fallback mock khi Supabase đã cấu hình.
- Resource Vault N+1 permission-query optimization.
- Additive DB indexes cho các query nóng.
- Manual regression checklist và UAT report.
- Preflight release script.

## Out of scope
- Workflow mới.
- Notification/Realtime.
- Jira sync hai chiều.
- Native mobile app.
- Tự động migrate/cut-over production data.
