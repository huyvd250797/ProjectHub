# ASC WORKING V3.4.1 - Document Drive Link Simplification

## Scope

V3.4.1 đơn giản hóa màn Document theo hướng lưu metadata nhẹ và link Google Drive.

## Changes

- Bỏ phụ thuộc Google Drive OAuth ở màn `/documents`.
- Thêm tài liệu bằng form: tiêu đề, loại tài liệu, liên kết nghiệp vụ, mô tả và link Google Drive.
- Lưới tài liệu có nút **Xem file** mở link Drive trực tiếp trong tab mới.
- Settings và Readiness chuyển trạng thái Document sang Drive Link Registry.

## Non-goals

- Không upload file vào ASC-WORKING.
- Không proxy nội dung file qua API.
- Không thay đổi dữ liệu ISSUE, PLHĐ, Plan, Finance, Workload hoặc Allocation.
- Không bắt buộc migration mới.
