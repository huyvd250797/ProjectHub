# ASC WORKING V2.4.0 - Validation

## Checklist chức năng

- Navbar hiển thị module **Workload** và có thể đổi tên/kéo thứ tự trong Navbar Modules Manager.
- Mở `/workload` hiển thị đúng project đang chọn.
- Demo Mode vẫn có dữ liệu mẫu nếu chưa cấu hình Supabase.
- API `/api/workload?projectId=...` trả về summary, members, suggestions, risks và calendar.
- Nhân sự có ISSUE/task quá hạn hoặc blocked được tăng Capacity Score.
- Nhân sự ít việc được đưa vào Assignment Suggestions.
- Dữ liệu dài trong bảng Workload xuống hàng và hưởng Global Grid UX của V2.2.2.
- Command Center có quick link sang Workload.

## Kiểm tra kỹ thuật

Chạy:

```bash
npm run preflight
npm run typecheck
npm run lint
npm run build
```

## Kỳ vọng

- Không cần chạy migration mới.
- Readiness có check **Workload & Capacity Planning**.
- Health endpoint trả feature `workload-dashboard`, `capacity-score`, `overload-detection`, `assignment-suggestions`, `capacity-calendar`.
