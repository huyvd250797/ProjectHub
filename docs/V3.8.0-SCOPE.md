# ASC WORKING V3.8.0 - Execution Task Grid

## Mục tiêu

Chuẩn hóa màn Execution Tasks thành grid quản trị task đầy đủ, dễ tìm kiếm/lọc và không mất thông tin Estimate sau khi lưu.

## Phạm vi

- Grid gồm Mã task, Tên task, Mô tả, Thuộc stage, Deadline, Estimate, Trạng thái task, Ưu tiên, Người phụ trách và Thao tác.
- Mã task tự tăng theo từng Project, không thay đổi khi xóa hoặc sắp xếp lại task.
- Tìm kiếm đồng thời trên toàn bộ trường task.
- Filter riêng theo từng cột; deadline hỗ trợ quá hạn/hôm nay/7 ngày tới/chưa có hạn; estimate hỗ trợ các khoảng giờ.
- Resize và kéo thả cột; lưu layout theo từng Project; reset về mặc định.
- API đọc/ghi `estimated_hours` và trả thông báo xác nhận giá trị vừa lưu.

## Database

Chạy `supabase/migrations/202609150001_v380_execution_task_grid.sql` trước khi deploy source mới.

Migration an toàn khi chạy lại, backfill mã cho task hiện hữu theo thời điểm tạo và giữ unique trong phạm vi Project.
