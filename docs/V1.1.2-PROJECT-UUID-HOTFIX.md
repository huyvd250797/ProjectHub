# ASC WORKING V1.1.2 — Project UUID Compatibility Hotfix

## Root cause
The seeded EPU project uses `00000000-0000-0000-0000-0000000000e1`. PostgreSQL accepts this value as `uuid`, but the V1.1.1 ISSUE validator required RFC version 1–5 and variant bits. The create form therefore reported `Project không hợp lệ` even though the selected project was valid in Supabase.

## Fix
ISSUE UUID validation now accepts canonical PostgreSQL UUID text: `8-4-4-4-12` hexadecimal groups.

## Migration
No Supabase migration is required.
