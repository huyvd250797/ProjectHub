# ASC WORKING V1.9.0 — Scope

Cross-Project Portfolio Dashboard

## Goal

V1.9.0 đưa ASC WORKING từ quản lý từng project riêng lẻ lên màn điều hành nhiều project. Người quản lý có thể xem project nào trễ, project nào có blocker, issue quá hạn, reminder quá hạn và nên xử lý trước việc gì.

## Added

- Module `/portfolio` mới trong sidebar.
- API `/api/portfolio` tổng hợp dữ liệu từ tất cả project user có quyền truy cập.
- KPI tổng: số project, project At Risk/Late, open issues, reminders và tổng giá trị hợp đồng.
- Project Ranking theo alert score.
- Priority Board liệt kê project cần xử lý trước.
- Demo portfolio data khi chưa kết nối Supabase.

## Catalog Delete Upgrade

- Danh mục Phòng ban và Danh mục Module có checkbox từng dòng.
- Check all chọn toàn bộ dòng đang hiển thị theo bộ lọc hiện tại.
- Bulk delete bằng hard delete, không archive.
- Phòng ban chỉ xóa khi chưa được dùng bởi ISSUE, People hoặc Module owner.
- Module chỉ xóa khi chưa được dùng bởi ISSUE, Contract Detail hoặc Module con.
- Dòng đang được sử dụng sẽ được giữ lại và báo số lượng bị chặn.

## Not Included

- Cảnh báo portfolio gửi ra email/SMS.
- Biểu đồ tài chính chi tiết theo tháng.
- Phân quyền cấu hình threshold rủi ro theo từng tổ chức.
