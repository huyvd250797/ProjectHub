# ASC WORKING V3.3.0 - AI Project Copilot

Nâng cấp ASC WORKING thành trợ lý điều hành dự án dựa trên dữ liệu hiện có trong hệ thống.

## Mục tiêu

- Tự tóm tắt tình hình dự án cho quản lý.
- Đề xuất việc cần xử lý trước.
- Cảnh báo rủi ro vận hành từ ISSUE, Timeline, Workload và Finance.
- Sinh draft báo cáo nhanh để copy gửi nội bộ.

## Phạm vi chức năng

- Thêm module **AI Copilot** trên navbar.
- Thêm API `/api/copilot`.
- Tổng hợp dữ liệu từ:
  - Master Plan, Stage, Task, Milestone, Reminder.
  - ISSUE backlog, overdue, near due.
  - Workload, capacity, overload, assignment suggestions.
  - Finance forecast %, actual %, revenue, profit, margin.
- Sinh **Executive Signal** với health score và confidence.
- Sinh **Next Best Actions** theo mức độ ưu tiên.
- Sinh **Risk Radar** theo nhóm Timeline, ISSUE, Workload, Finance.
- Sinh **Report Writer** dạng báo cáo nhanh có nút copy.
- Bổ sung **Prompt Templates** để chuẩn bị cho AI API thật ở các bản sau.

## Kỹ thuật

- Bản này dùng rule engine phía server, chưa bắt buộc OpenAI API key.
- Không tạo bảng mới.
- Không cần migration mới nếu project đã lên đến V3.2.3.
