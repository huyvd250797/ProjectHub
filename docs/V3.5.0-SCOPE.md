# ASC WORKING V3.5.0 - Due Date Notification Automation

## Mục tiêu

Tự động tạo cảnh báo vào Notification Center cho các đầu việc có `due_date` liên quan trực tiếp tới user hiện tại.

## Phạm vi

- ISSUE: cảnh báo theo `issues.due_date` khi người phụ trách ISSUE có `people.user_id = auth.uid()`.
- Plan Task: cảnh báo theo `project_plan_tasks.due_date` khi người phụ trách task là user hiện tại.
- Milestone: cảnh báo theo `project_milestones.due_date` khi owner milestone là user hiện tại.
- Các mốc cảnh báo:
  - Trước 3 ngày.
  - Trước 1 ngày.
  - Đến hạn hôm nay.
  - Đã quá hạn.
- Cảnh báo được đưa vào bảng `notifications` với category `due_reminder`.
- Tôn trọng cấu hình nhận thông báo `notification_preferences.due_reminders`.
- Chống trùng bằng `notification_key` dạng `due-v350:*`.

## Không làm trong phiên bản này

- Không gửi email/push ngoài app.
- Không thêm job scheduler server riêng.
- Không thay đổi UI lớn của Notification Center.
- Không tự động sửa due date hoặc trạng thái công việc.

## Migration

Chạy migration:

```sql
supabase/migrations/202609110001_v350_due_date_notification_automation.sql
```

Migration tạo function mới `sync_due_date_notifications_v350(project_id)` và giữ wrapper legacy `sync_issue_due_notifications_v110(project_id)` để các luồng cũ vẫn hoạt động.

## Luồng hoạt động

1. Người dùng mở Notification Center hoặc API notification được gọi.
2. Server gọi `sync_due_date_notifications_v350(projectId)`.
3. Database rà các ISSUE, Plan Task và Milestone của user hiện tại.
4. Nếu due date rơi vào mốc 3 ngày, 1 ngày, hôm nay hoặc quá hạn, app tạo notification.
5. Nếu notification đã tồn tại cùng key thì không tạo trùng.
