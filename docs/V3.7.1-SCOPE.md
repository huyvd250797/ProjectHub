# ASC WORKING V3.7.1 - Search, Modal & Deadline Fix

## Mục tiêu

Ổn định các thao tác vận hành hay dùng: tìm kiếm toàn hệ thống, tìm kiếm ISSUE, modal Plan và kiểm soát đúng hạn/trễ hạn của Project.

## Phạm vi nâng cấp

- Global Search trên Topbar gọi gợi ý sau khi người dùng dừng nhập 1 giây.
- Kết quả search hiển thị module, nội dung khớp, badge và link đi đến màn dữ liệu.
- ISSUE search chỉ chạy khi nhấn Enter.
- Dashboard Project bổ sung số ngày trễ hạn.
- Master Console bắt buộc nhập Ngày hoàn thành khi chuyển Project sang Completed.
- Plan modal render bằng portal để không bị lệch do animation/transform của page.

## Migration

Chạy migration:

```sql
supabase/migrations/202609140001_v371_search_modal_deadline_fix.sql
```

Migration thêm cột `projects.completed_date` để lưu ngày hoàn thành thực tế.
