# ASC WORKING V2.6.0 - Validation

## Resource Scheduling

- Chạy migration V2.6.0 thành công sau V2.5.0.
- Navbar có module **Phân bổ**.
- Mở `/resource-scheduling` theo project đang chọn.
- Board hiển thị 6 tuần từ ngày bắt đầu đang chọn.
- Date input ngày bắt đầu cho phép nhập `DD/MM/YYYY` và bấm icon lịch để chọn date picker.
- Queue **Việc chưa phân công** hiển thị ISSUE/task chưa có assignee/owner.
- Kéo ISSUE/task từ queue sang ô nhân sự cập nhật được người phụ trách.
- Kéo ISSUE/task từ nhân sự này sang nhân sự khác cập nhật được người phụ trách.
- Combobox trên card cũng cập nhật được người phụ trách.
- Khi phân công vượt capacity tuần, UI hiển thị cảnh báo overload.
- Tắt/mở lại trang vẫn thấy dữ liệu phân công mới vì lấy từ Supabase.

## Regression

- Workload V2.5.0 vẫn tính Planned/Available/Overload theo giờ.
- ISSUE drawer và Plan Task modal vẫn nhập được **Giờ ước tính**.
- Các date picker cũ trong Plan, ISSUE, Reports, Project Console vẫn hiển thị `DD/MM/YYYY`.
- Double-click navbar reload module vẫn hoạt động.
- Readiness có check **Resource Scheduling & Assignment Board**.
- Health endpoint trả version `2.6.0`.
