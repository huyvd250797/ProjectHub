# ASC WORKING V3.6.0 - UI/UX Performance Stabilization

## Mục tiêu

Làm giao diện mượt hơn, phản hồi nhanh hơn và giảm cảm giác lag khi dự án có nhiều ISSUE, PLHĐ, nhân sự, tài chính hoặc kế hoạch.

## Phạm vi nâng cấp

- Client cache hỗ trợ stale-while-revalidate:
  - Người dùng thấy dữ liệu cache ngay khi còn trong khoảng stale an toàn.
  - App tự refresh nền để lần mở sau nhanh hơn.
  - Vẫn có `force` khi người dùng bấm refresh thủ công.
- Workspace warmup:
  - Sau khi vào Project, app tự preload nhẹ các API hay dùng: ISSUE preferences/views, Workload, Allocation, Finance và Notifications.
  - Warmup chạy lúc browser rảnh để không chặn màn hiện tại.
- UI motion:
  - Page enter animation nhẹ khi đổi màn hoặc double-click reload navbar.
  - Tôn trọng `prefers-reduced-motion`.
- Skeleton loading:
  - Workspace loading dùng shimmer skeleton ổn định hơn.
  - Không thay đổi dữ liệu nghiệp vụ.
- Global grid UX:
  - Các bảng auto-enhanced có nút **Reset layout cột** để đưa thứ tự/độ rộng cột về mặc định.
  - Tiếp tục giữ drag/drop cột, resize cột và wrap nội dung.
