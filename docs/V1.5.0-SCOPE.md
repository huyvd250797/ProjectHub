# ASC WORKING V1.5.0 — ISSUE Visual Customization & Workspace Layout

## Phạm vi

V1.5.0 tập trung vào khả năng cá nhân hóa màn hình ISSUE và điều hướng workspace mà không thay đổi dữ liệu nghiệp vụ.

1. Màu tag ISSUE
   - Bốn nhóm: Trạng thái, Trạng thái KH, Ưu tiên, Phụ trách.
   - Từng giá trị được cấu hình độc lập màu viền, background và chữ.
   - Có preview, khôi phục từng giá trị và khôi phục cả nhóm.
2. Thứ tự cột ISSUE
   - Kéo tiêu đề cột và thả tại vị trí mong muốn.
   - Thứ tự đồng bộ với cửa sổ Cấu hình cột hiện có.
3. Bộ lọc ISSUE
   - Nút Ẩn lọc/Hiện lọc trên toolbar.
   - Mặc định hiển thị; việc ẩn thanh lọc không xóa điều kiện lọc đang áp dụng.
4. Navbar trái
   - Cửa sổ sắp xếp module bằng kéo-thả hoặc mũi tên.
   - Không cho mất module: API tự chuẩn hóa và bổ sung mục còn thiếu.

## Phạm vi lưu cấu hình

| Cấu hình | Phạm vi |
|---|---|
| Màu tag, thứ tự cột, ẩn/hiện bộ lọc | Tài khoản + Project |
| Thứ tự module navbar | Tài khoản, dùng chung toàn workspace |

