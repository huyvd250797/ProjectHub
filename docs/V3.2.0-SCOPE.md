# ASC WORKING V3.2.0 - Project Timeline Pro

## Mục tiêu

Nâng cấp Timeline/Gantt trong module Kế hoạch thành công cụ điều phối tiến độ chuyên nghiệp, vẫn dùng chung Master Plan, Project Stages, Execution Tasks và Milestones hiện có.

## Phạm vi

- Baseline snapshot cho stage/task để so sánh kế hoạch gốc với lịch hiện tại.
- Tính và hiển thị số ngày trễ, cảnh báo stage/task quá hạn.
- Đánh dấu Critical Path theo các stage critical của kế hoạch.
- Kéo thả stage để đổi khoảng ngày; kéo thả task để đổi deadline.
- Hiển thị milestone, target date, current plan và baseline trên cùng một Gantt.
- Chỉ Admin/PM được snapshot hoặc chỉnh lịch; Viewer chỉ xem.
- Migration có thể chạy độc lập sau V3.1.0, không phá dữ liệu cũ.
