# ASC WORKING V0.9.3 — Deploy Type Fix

## Vercel error fixed

The production build reported `TS2352` because Supabase inferred `.select(MASTER_PROJECT_SELECT)` as `GenericStringError`.

## Root cause

`MASTER_PROJECT_SELECT` was built using:

```ts
[...columns].join(",")
```

That produces a runtime `string`, so the Supabase PostgREST TypeScript parser cannot infer the selected columns.

## Fix

The select is now a compile-time literal:

```ts
export const MASTER_PROJECT_SELECT = "id,code,...,updated_at" as const;
```

The Master Project normalizers also accept `unknown` and safely normalize objects, eliminating direct `GenericStringError -> Record<string, unknown>` casts.

## Database

No SQL migration is required for this deploy fix.
