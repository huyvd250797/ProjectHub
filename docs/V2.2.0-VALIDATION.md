# ASC WORKING V2.2.0 — Validation

## PLHĐ Tree

- Mở màn PLHĐ và xác nhận chỉ còn một bảng cây.
- Cây hiển thị đúng thứ tự: Nhóm -> Phân hệ -> Module -> Chức năng.
- Click biểu tượng mở/thu gọn ở Nhóm, Phân hệ, Module để kiểm collapse / expand.
- Import file có `subsystem`, `module`, `other` và xác nhận `other` xuất hiện là Chức năng dưới Module.

## Catalog

- Mở Danh mục PLHĐ.
- Xác nhận chỉ dùng tab PLHĐ cho cả Nhóm / Phân hệ / Module và Chức năng.
- Sửa một Chức năng, lưu lại, reload màn PLHĐ và kiểm tra dòng ngoài thay đổi theo.
- Xóa một Chức năng chưa có con, reload màn PLHĐ và kiểm tra dòng ngoài biến mất.

## Status

- Trên màn PLHĐ, đổi trạng thái trực tiếp ở dòng Phân hệ hoặc Module.
- Xác nhận Nhóm và Chức năng không có combobox trạng thái.
- Reload PLHĐ và kiểm tra trạng thái vẫn giữ giá trị mới.

## Project Delete

- Vào Master Project Console, mở một Project test.
- Chọn Xóa Project, nhập sai mã và xác nhận thao tác không chạy.
- Nhập đúng mã Project test và xác nhận Project biến mất khỏi danh sách.
- Kiểm tra các bảng theo `project_id` không còn dữ liệu của Project test.

## Automated Checks

- `npm run preflight`
- `npm run typecheck`
- `npm run lint`
- `npm run build`
