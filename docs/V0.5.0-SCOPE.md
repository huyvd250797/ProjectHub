# ASC WORKING V0.5.0 — Department Intelligence / Phòng ban

## Mục tiêu
Biến màn hình Phòng ban từ skeleton thành intelligence view đọc dữ liệu thật theo project.

## In scope
- Project-scoped department aggregate.
- Department KPI table.
- Search / filter / sort.
- Handover progress.
- Stakeholder contacts.
- PLHĐ Modules owned by department.
- Attention ISSUE preview.
- Drill-down ISSUE.
- Unassigned department bucket.
- Dashboard → Department deep link.

## Out of scope
- CRUD/merge/rename Department.
- CRUD People.
- Inline update ISSUE.
- Full ISSUE filtering implementation.

Các thao tác ghi dữ liệu sẽ được triển khai cùng V0.6.0+ để tránh trộn read-intelligence với transaction workflow.
