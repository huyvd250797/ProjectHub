# ASC WORKING V1.2.0 — Advanced Analytics & Project Health

## Mục tiêu
Biến dữ liệu vận hành đã có trong ASC WORKING thành lớp Project Intelligence cho PM: Health Score, xu hướng ISSUE, backlog aging, risk ranking và workload.

## In scope
- Advanced Analytics theo Project.
- Project Health Score 0–100 với 5 thành phần: ISSUE, bàn giao, quá hạn, chất lượng dữ liệu, kế hoạch.
- Xu hướng ISSUE tạo mới / xử lý theo 30/90/180/365 ngày hoặc toàn bộ.
- Backlog Aging.
- Phân bổ trạng thái / ưu tiên.
- Top risk Module / Phòng ban / Thành viên.
- Drill-down về ISSUE đã lọc.
- Export CSV Project Health.
- Ẩn/hiện giá trị hợp đồng trên Dashboard.
- ISSUE page size: 50 / 100 / 500 / 1000 / ALL.
- ALL tải dữ liệu theo chunk server-side để tương thích giới hạn PostgREST.

## Out of scope
- Jira Integration.
- AI prediction.
- Cross-project executive portfolio dashboard.
