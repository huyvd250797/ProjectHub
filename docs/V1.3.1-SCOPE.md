# ASC WORKING V1.3.1 — Project Master Data & Wide Modal UX

## Mục tiêu

V1.3.1 bổ sung khả năng khai báo dữ liệu danh mục trực tiếp trên từng Project và tối ưu các form nhập nhiều trường để giảm scroll dọc.

## Project Master Data

### Phòng ban theo Project
- Truy cập từ màn **Phòng ban** → **Danh mục Phòng ban**.
- MASTER/Admin/PM được thêm và chỉnh sửa.
- Member/Viewer xem danh mục ở chế độ read-only.
- Trường dữ liệu: Mã phòng ban, Tên phòng ban, Đang sử dụng.
- Dữ liệu ghi trực tiếp vào `public.departments`, luôn khóa theo `project_id`.
- Tên được chuẩn hóa vào `normalized_name` để giữ ràng buộc chống trùng của schema hiện tại.

### Module PLHĐ theo Project
- Truy cập từ màn **PLHĐ** → **Danh mục Module**.
- Trường dữ liệu: Mã Module, Tên Module, Phân hệ/Nhóm cha, Phòng ban phụ trách, Trạng thái Module, Phân loại, Thứ tự.
- Dữ liệu ghi trực tiếp vào `public.contract_items` với `item_type='module'` và `project_id` của Project đang chọn.
- Sau khi lưu, PLHĐ, Phòng ban Intelligence và ISSUE tự reload lookup/dữ liệu liên quan.

## Wide Modal UX
Các màn nhập nhiều thông tin được chuyển từ drawer bên phải sang modal rộng:
- Tạo/Sửa ISSUE: max width 1180px, nhóm field 4 cột ở desktop.
- Hồ sơ Project/Project Team: max width 1240px.
- Resource Vault create/edit/view: max width 1040px.
- Modal vẫn giới hạn chiều cao theo viewport và chỉ scroll bên trong nội dung cần thiết.
