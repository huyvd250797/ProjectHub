# Setup V1.1.1

## 1. Điều kiện
Database đã chạy migration đến V1.1.0.

## 2. Chạy migration mới
Trong Supabase SQL Editor chạy:

`supabase/migrations/202608260001_v1111_team_validation_performance.sql`

Migration này:
- thêm `people.is_active`;
- thêm index Project Team;
- tạo RPC `get_issue_summary_v1111`;
- bật `pg_trgm` và index tìm kiếm ISSUE/nhân sự.

## 3. Project Team mới
Trong Master Console → Project → Thành viên:
- Họ tên: bắt buộc;
- Email đăng nhập: không bắt buộc;
- Role: bắt buộc.

Không có email: nhân sự vẫn xuất hiện ở Phụ trách ISSUE.

Có email nhưng chưa có Supabase Auth: hệ thống lưu email nhưng chưa cấp login.

Khi tài khoản Supabase Auth đã được tạo: mở lại nhân sự, nhập/giữ đúng email và bấm Lưu. Hệ thống tự link login + project_members.

## 4. Test ISSUE
- Bỏ Nội dung và bấm Tạo ISSUE → phải báo đúng `Nội dung ISSUE là bắt buộc`.
- Nhập Jira sai URL → báo ngay Link Jira.
- Chọn nhân sự chưa có email làm Phụ trách → vẫn tạo ISSUE thành công.
