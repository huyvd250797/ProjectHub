# V3.3.0 — Validation Guide

## Kiểm tra tự động

```bash
npm run preflight
npm run typecheck
npm run lint
npm run build
```

## Kiểm tra thủ công

1. Đăng nhập và chọn một Project có dữ liệu thật.
2. Mở `Thiết lập → Data Integrity & Source of Truth`.
3. Bấm `Chạy lại`, xác nhận score, status và 5 nhóm Catalog, ISSUE, Plan, Finance, Workload.
4. Chọn từng finding, bấm `Mở màn sửa`, chỉnh dữ liệu qua màn nghiệp vụ tương ứng.
5. Chạy lại audit; finding đã xử lý phải biến mất hoặc giảm mức độ.
6. Mở `Hardening & UAT`, xác nhận readiness hiển thị thêm `Data Integrity & Source of Truth`.
7. Gọi `GET /api/health`, xác nhận `version=3.3.0`, `release=Data Integrity & Source of Truth` và các feature source-of-truth.

## Tiêu chí đạt

- Không có lỗi TypeScript, lint hoặc build.
- Demo Mode vẫn mở được dashboard với báo cáo mẫu.
- Project thật không có lỗi query schema ngoài phạm vi migration hiện có.
- Audit không tự ghi dữ liệu và không thay đổi dữ liệu khi chỉ bấm chạy kiểm tra.
