- `npm run preflight`
- `npm run typecheck`
- `npm run build`
- `npm run lint`

## UAT AI Copilot

1. Mở navbar **AI Copilot**.
2. Kiểm tra màn hình load đúng project hiện tại.
3. Kiểm tra **Executive Signal** hiển thị health score, trạng thái và confidence.
4. Kiểm tra **Next Best Actions** có đề xuất từ ISSUE, task, workload hoặc finance.
5. Kiểm tra **Risk Radar** có cảnh báo theo từng domain.
6. Kiểm tra **Report Writer** sinh nội dung báo cáo nhanh.
7. Bấm **Copy** và dán ra ngoài để xác nhận nội dung report được copy.
8. Double-click navbar **AI Copilot** để reload lại dữ liệu.
9. Kiểm tra `/api/health` có feature `ai-project-copilot`.
10. Kiểm tra readiness có mục **AI Project Copilot**.

## Database

Không cần migration mới. Module đọc dữ liệu từ các bảng hiện có của Plan, ISSUE, Workload và Finance.
