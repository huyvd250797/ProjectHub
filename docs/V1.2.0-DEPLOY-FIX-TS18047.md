# V1.2.0 Deploy Fix — TS18047

## Lỗi
`app/api/issues/route.ts(150,22): error TS18047: 'supabase' is possibly 'null'.`

## Nguyên nhân
`createClient()` có thể trả về `null` khi Supabase chưa được cấu hình. Route đã guard trường hợp này, nhưng `buildRowsQuery()` là local function declaration và TypeScript không giữ narrowing của biến `supabase` từ outer scope vào function đó.

## Fix
Sau guard, tạo client ổn định `const db = supabase` và dùng `db` cho toàn bộ GET ISSUE, đặc biệt trong `buildRowsQuery()`. `db` được suy luận là non-null.

Bản DeployFix cũng giữ lại migration Analytics V1.2.0 đã sửa cú pháp PostgreSQL `FILTER`.
