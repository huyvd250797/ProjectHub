# ASC WORKING V2.0.0 — Scope

Project Command Center

## Added

- Module mới `/command-center` để điều hành project đang chọn trong một màn tổng hợp.
- API `/api/command-center` gom dữ liệu Project, ISSUE, PLHĐ, Master Plan, Execution Task, Milestone và Smart Reminder.
- Health Score tổng hợp tiến độ kế hoạch, execution progress, overdue ISSUE, blocked task và overdue reminder.
- Action Board liệt kê việc cần xử lý trước trong 7 ngày tới.
- Risk Radar gom cảnh báo thông minh từ Plan và dữ liệu ISSUE thiếu assignee.
- Delivery Timeline hiển thị stage, ngày bắt đầu/kết thúc và progress.
- Command Links mở nhanh Plan, ISSUE, PLHĐ và Portfolio.

## Navbar Enhancements

- Double-click item navbar để reload lại giao diện và dữ liệu của module đó.
- AppShell lắng nghe event `asc-working:navbar-reload` để remount màn hình hiện tại.
- Cấu hình Navbar Modules bổ sung cột **Tên gốc** không sửa và ô **Tên hiển thị** có thể chỉnh.
- Tên hiển thị được lưu theo user trong `workspace_user_preferences.navigation_order` dạng JSONB tương thích ngược.

## Database

- Không có migration mới cho V2.0.0.
- Cần database đã chạy đầy đủ schema đến V1.9.2 để Command Center có đủ nguồn dữ liệu tổng hợp.
