# ASC WORKING V3.6.1 - Modal Save Close & Data Visibility Fix

## Mục tiêu

Rà các modal/form thêm mới hoặc chỉnh sửa để đảm bảo:

- Lưu thành công thì modal/drawer đóng lại, không giữ giao diện nhập với nội dung cũ.
- Dữ liệu vừa nhập được hiển thị lại ở lưới hoặc chi tiết sau khi lưu.
- Không thay đổi luồng nghiệp vụ đang đúng, không thêm migration.

## Màn hình bị lỗi và đã fix

| Màn hình | Lỗi tìm thấy | Cách xử lý |
| --- | --- | --- |
| ISSUE | Sau khi tạo/cập nhật ISSUE, drawer vẫn mở bằng cách chuyển sang chi tiết ISSUE vừa lưu. | Đóng drawer, clear `issueId` khỏi URL, cập nhật row hiện có trong state và reload lại dữ liệu ISSUE. |

## Màn hình đã rà và không phát hiện lỗi đóng modal

| Màn hình | Kết quả rà |
| --- | --- |
| Plan - Master Plan / Auto Generate / Stage / Milestone / Task / Reminder / Checklist | `onSaved` gọi handler chung, đóng modal và reload kế hoạch. |
| Finance - Thêm/sửa tháng tài chính | Lưu thành công `setEditor(null)` và reload dữ liệu tài chính. |
| Document - Thêm/sửa/sao chép tài liệu | `onDone` đóng modal và reload danh sách. Link Drive được ẩn theo yêu cầu trước đó. |
| Resource Vault - Thêm/sửa tài nguyên | Lưu thành công gọi `closeDrawer()` và reload danh sách. |
| Master Project - Tạo project mới | Tạo thành công đóng modal tạo mới và mở hồ sơ project. |
| Navbar manager | Lưu thành công đóng modal cấu hình navbar. |
| Quick Import | Import xong chủ động giữ màn hình kết quả để người dùng xem thống kê, có nút đóng và xem dữ liệu. |

## Không thay đổi

- Không thêm bảng/cột mới.
- Không đổi API contract.
- Không đổi các màn import có bước kết quả/confirm chủ động.
