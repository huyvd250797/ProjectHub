# UAT V1.3.1 — Project Master Data & Wide Modal UX

## Danh mục Phòng ban
- [ ] Chọn Project A → mở Phòng ban → Danh mục Phòng ban.
- [ ] Thêm phòng ban mới chỉ xuất hiện trong Project A.
- [ ] Project B không nhìn thấy phòng ban của Project A.
- [ ] Sửa mã/tên phòng ban thành công.
- [ ] Tắt `Đang sử dụng` → phòng ban không còn nằm trong lookup ISSUE active.
- [ ] Tên trùng trong cùng Project trả thông báo rõ ràng.
- [ ] Member/Viewer không có nút lưu.

## Danh mục Module PLHĐ
- [ ] Chọn Project A → PLHĐ → Danh mục Module.
- [ ] Tạo Module mới với tên bắt buộc.
- [ ] Chọn được Phân hệ/Nhóm cha hiện có.
- [ ] Chọn được Phòng ban phụ trách của đúng Project.
- [ ] Module mới xuất hiện trong PLHĐ và lookup Module của ISSUE sau khi lưu.
- [ ] Không cho gán parent/phòng ban từ Project khác qua API.
- [ ] Member/Viewer chỉ xem.
