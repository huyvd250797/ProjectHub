# ASC WORKING V0.4.0 — PLHĐ Unified View

## Mục tiêu
Đưa PLHĐ từ skeleton sang màn hình nghiệp vụ đọc dữ liệu Supabase thật theo `project_id`, giữ một route `/contract` với hai kiểu xem.

## Đã triển khai
- Tổng quan PLHĐ theo project.
- Chi tiết PLHĐ dạng tree.
- Virtualized rendering cho dữ liệu 5.000+ dòng.
- Search mã/nội dung/ghi chú.
- Filter Loại, Phòng ban, Trạng thái Module.
- Filter theo Module khi xem tree.
- Expand đến cấp 2 / collapse all.
- Click Module ở tổng quan -> chuyển sang Chi tiết và focus Module.
- Click ISSUE count -> `/issues?moduleId=...`.
- Drawer chi tiết node PLHĐ.
- Hiển thị mapping / chưa mapping.
- Summary: Phân hệ, Module, chi tiết, ISSUE, bàn giao, còn lại.
- Server-side RPC `get_project_contract(project_id)`.

## UX fixes cùng release
1. Click logo ASC WORKING reload trang hiện tại.
2. Spinner đăng nhập tiếp tục quay từ lúc submit đến khi trang login unmount sau redirect thành công.
